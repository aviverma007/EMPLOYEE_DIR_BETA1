 ☐ Check backend/.env file exists
 ☐ Run setup_first_time.bat again
 ☐ Check port 8001 is not in use: netstat -ano | findstr :8001


 IF FRONTEND WON'T START:
 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
 ☐ Check frontend/.env has: REACT_APP_BACKEND_URL=http://localhost:8001
 ☐ Run setup_first_time.bat again
 ☐ Delete frontend/node_modules and run: npm install
 ☐ Check port 3000 is not in use: netstat -ano | findstr :3000


 IF APP SHOWS ERRORS:
 ━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

 ☐ Check frontend terminal for error messages
 ☐ Clear browser cache (Ctrl + Shift + Delete)
 ☐ Try in different browser (Chrome recommended)
