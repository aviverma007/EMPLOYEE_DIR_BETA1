🎯 FIRST TIME SETUP (Do Once)
================================================================================

STEP 1: Install Requirements (5 minutes)
-----------------------------------------
Download and install these 3 programs:

1. Python 3.8+
   Download: https://python.org/downloads/
   ✓ Check "Add Python to PATH" during install

2. Node.js 16+
   Download: https://nodejs.org/
   Choose: LTS version (recommended)

3. MongoDB
   Download: https://mongodb.com/try/download/community
   ✓ Check "Install MongoDB as a Service"
   ✓ Check "Install MongoDB Compass"


STEP 2: Run First-Time Setup (5-10 minutes)
--------------------------------------------
Double-click this file:
   📁 setup_first_time.bat

Wait for it to complete. It will:
   ✓ Install backend dependencies
   ✓ Install frontend dependencies
   ✓ Create configuration files


STEP 3: Start MongoDB
---------------------
Option A (Easiest):
   1. Press Windows Key
   2. Type "PowerShell"
   3. Right-click "Windows PowerShell"
   4. Click "Run as administrator"
   5. Type: net start MongoDB
   6. Press Enter

Option B (If Option A fails):
   1. Open "MongoDB Compass" program
   2. It should start MongoDB automatically
   3. Keep it open

1. Make Sure MongoDB is Running

================================================================================
❗ IF SOMETHING DOESN'T WORK
================================================================================

Problem: "MongoDB connection failed"
Solution:
   - Open PowerShell as Administrator
   - Run: net start MongoDB

Problem: "Port 8001 already in use"
Solution:
   - Run: netstat -ano | findstr :8001
   - Run: taskkill /PID <number> /F
   - Replace <number> with the number you see

Problem: "Module not found" errors
Solution:
   - Run setup_first_time.bat again

Problem: Can't see employees in the app
Solution:
   - Make sure backend shows "Successfully loaded 670 employees"
   - If not, restart backend
